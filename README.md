# F1 Team Manager Simulator · v0.5

Abra `index.html` no Chrome ou Edge. Não precisa instalar nada nem usar Live Server.

## Novidades da versão 0.5
- Centro de desenvolvimento técnico do carro.
- Quatro áreas: aerodinâmica, unidade de potência, chassi e suspensão.
- Cinco níveis de evolução por área.
- Projetos custam dinheiro e são concluídos ao fechar o mês.
- Apenas um projeto pode ficar ativo por vez.
- Melhorias e progresso são salvos no navegador.
- Migração automática dos dados da carreira v0.4 no mesmo navegador.

## Observações
Os custos e atributos são parâmetros fictícios de gameplay. O desempenho é um índice simplificado; ainda não altera uma simulação de corrida. A conclusão do projeto é instantânea ao fechar o mês, sem temporizador real.
