# F1 Team Manager Simulator

Primeiro marco do projeto: fundação da aplicação e início de carreira.

## Como executar
1. Extraia a pasta do projeto.
2. Abra a pasta no VS Code.
3. Inicie um servidor local (recomendado: extensão Live Server).
4. Abra `index.html` pelo servidor local.

> O projeto utiliza módulos JavaScript (`type="module"`), portanto não é recomendado abrir o HTML diretamente com `file://`.

## O que já funciona
- Seleção entre cinco equipes fictícias.
- Criação de carreira na temporada inicial.
- Painel geral da equipe.
- Visualização dos pilotos e atributos.
- Painel de desenvolvimento com atributos-base do carro.
- Calendário inicial provisório.
- Navegação entre as áreas.
- Salvamento e reinicialização da carreira via LocalStorage.

## Observações
- Equipes, pilotos e calendário são fictícios/provisórios.
- A simulação de corrida ainda não foi implementada nesta primeira entrega.
- Não são utilizados logotipos ou imagens oficiais de equipes.
